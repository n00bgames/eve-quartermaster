# EQM v1.0.3 — New Eden Atlas

Navigation gets a searchable Star Map with security, hourly activity, stations, agents, and routes. Missions & LP adds agent discovery, mission-reference links, linked-character LP balances, and searchable rewards showing LP, ISK and required-item costs. Send systems, agents or corporation stations directly to the existing route planner. Rust handles jump-distance calculations, with a Python fallback.

The first map is a flat EVE-style view. DOTLAN and zKillboard open as external references. LP balances require your own linked pilot with the loyalty-read scope; LP coverage does not guarantee every redemption requirement is met.

## Setup: download AND import the SDE

EQM needs imported static data for the map, stations, agents and item names. **The fetch scripts download files only. Downloading, updating EQM, or running ESI Sync does not import the SDE.**

1. Update/rebuild backend and frontend first. Normal backend startup applies migration `0081_mission_atlas`.
2. From the EQM checkout on your installation host, run `.\sde-fetch.bat` on Windows or `sh ./sde-fetch.sh` on Linux/macOS. The default output is `./sde/sde.zip`. Already downloaded a current YAML SDE? Reuse it. For remote installations, put it in the server's mounted SDE folder.
3. Sign in as admin: **Settings → SDE Import → `/sde/sde.zip` → Import SDE**. If you ran the fetch script with `extract`, use `/sde`. These paths assume the standard Docker mount.
4. Wait for successful completion, then use **Navigation → New Eden Atlas → Refresh data**. Full imports include agents. **Import agents only** is for installations whose remaining static data is already current.
