# EVE Quartermaster v2.0 — development release draft

**Unreleased draft.** Features and screenshots below are prepared in the 2.0.0 working tree. Public image links become available after the assets are pushed. Update this draft as the release grows; this file does not publish a release.

Local Scan turns a pasted pilot list into a public alliance and corporation breakdown, with recognizable logos, count badges, pilot details and saved red organization highlights. Choose a system, send its destination to selected linked characters, share a timed report, or export a branded PDF. Report owners, corporation directors and administrators get deletion controls within their permitted scope.

*Screenshots show the actual EQM interface with synthetic accounts and pilot memberships in a disposable local preview.*

![Local Scan with synthetic pilot memberships](https://raw.githubusercontent.com/n00bgames/eve-quartermaster/main/static/ss/v2.0/local-scan-summary-portraits.jpg)

Accounts can now hold **multiple roles**, with their permissions combined. The new **Intel Analyst** role supports utility use; Navigation and Market are available by default to every role. ESI authorization and collection follow the token owner's combined permissions, so utility-only accounts do not automatically contribute private assets, skills or industry data.

![Role editor with two utility roles selected](https://raw.githubusercontent.com/n00bgames/eve-quartermaster/main/static/ss/v2.0/multiple-roles.png)

The SDE importer now shows stored totals alongside this import's counters for all imported datasets, including celestial, Dogma, blueprint and PI details. These screenshots show an otherwise empty fixture with two systems and no completed import.

![Complete SDE totals overview](https://raw.githubusercontent.com/n00bgames/eve-quartermaster/main/static/ss/v2.0/sde-totals-overview.png)

[Nested counters and complete screenshot gallery](../screenshots.md#v20-development-previews) · [Capture provenance](../../static/ss/v2.0/capture-receipt.json) · [Implementation and rollout requirements](../local-scan.md)

Battle-report retention/PDF enhancements, themes and personalized navigation remain planned and should not be presented as shipped in this draft.

Asset Ledger gains **Load all records**: browse an entire accessible inventory snapshot, see row/unit/type totals and filter locally while table rendering stays paged. Regular item/owner searches now filter in SQL before loading details. Configurable bounded database pools expand during bursts and release overflow connections afterward; periodic housekeeping targets stale API reads and abandoned transactions within EQM's scope.

![Complete accessible inventory snapshot totals](https://raw.githubusercontent.com/n00bgames/eve-quartermaster/main/static/ss/v2.0/assets-all-records.png)

[Database settings, cleanup thresholds and rollout](../database-connections.md)

**D-Scan** now groups pasted directional scans by ship type,class and deployable, with item icons, observed/manual totals and base hull mass. Add known combat recons, link a local pilot list with saved organization highlights, choose a system and share a timed public report or branded PDF. Changes create new public snapshots, preserving previous links. Ownership is never inferred from ship names.

![D-Scan system and total summary with synthetic ships and pilots](https://raw.githubusercontent.com/n00bgames/eve-quartermaster/main/static/ss/v2.0/dscan-system-total.jpg)

[Manual recon controls](https://raw.githubusercontent.com/n00bgames/eve-quartermaster/main/static/ss/v2.0/dscan-editor.png) · [D-Scan formats and rollout](../dscan.md)

Large scan reports now grow with their content, so ship lists and opened object tables use the page scrollbar on desktop and mobile.

Saved organization highlights now update open scan lists immediately, including pilot names and count badges. Public links and PDFs retain their saved snapshot; a notice explains when a new report is needed to share current markings.

Local Scan and D-Scan now put the selected system and total pilots/ships at the top. Local totals include unresolved pasted names with an explicit split; ship totals identify observed and manual counts. Both PDF exports repeat system and totals on every page. Expanded corporation lists include compact pilot portraits that open zKillboard in a new tab.
